# GraphCh10

Formalizing Chapter 10 Exercises from "Discrete Mathematics and Its Applications" by Kenneth H. Rosen


### Interactive Visualizations

To explore the interactive visualization for a Lean exercise, open a terminal in the project's root directory and run:

```powershell
py visualizations\supp09a.py
```

Replace `09a` with the corresponding exercise number if its visualization is available.

Each visualization provides an interactive walkthrough of the graph theory concepts, mathematical reasoning, and corresponding Lean proof. You can modify graph examples, explore vertex sets, and follow the proof step by step.
